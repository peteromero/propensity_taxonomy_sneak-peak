# propensity_taxonomy_sneak-peak

These three constructs are a typed sample of propensities with known interaction in human samples. Conscientiousness is a Level-2 trait of constraint and dutiful control \cite{Costa1992}. Need for power is a Level-2 McClelland motive to have impact and control, and is not the same object as a Schwartz Power value \cite{McClelland1961}. Universalism is a Level-2 Schwartz value: concern for the welfare of all others, opposite Power on the circumplex \cite{Schwartz1992}. Together they specify one interaction — constraint $\times$ dominance-motive $\times$ impartial care — so a pipeline can be written without collapsing the three into a single $\theta$. Further constructs, including cooperative and competitive assemblies, wait on the forthcoming taxonomy preprint.
